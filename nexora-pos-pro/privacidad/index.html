NEXORA POS PRO

Política de privacidad

Información sobre el tratamiento, almacenamiento y protección de datos en la aplicación Android de punto de venta.

Última actualización: 20 de noviembre de 2026

Esta política se refiere a NEXORA POS PRO. Los datos comerciales se conservan principalmente en el dispositivo del establecimiento; algunas funciones permiten exportarlos o sincronizarlos con dispositivos autorizados.

1. Identificación y alcance

NEXORA POS PRO es una aplicación Android para la administración de puntos de venta, inventarios, compras, proveedores, clientes, empleados, caja, cotizaciones y reportes. El producto es desarrollado y distribuido bajo la denominación NEXORA. Esta política describe las operaciones de datos de la edición local de NEXORA POS PRO revisada para su publicación.

Cada establecimiento que utiliza la aplicación determina qué información comercial introduce, quién puede acceder a ella y durante cuánto tiempo la conserva.

2. Información que puede procesar la aplicación

De acuerdo con las funciones que habilite el establecimiento, la aplicación puede procesar: (a) datos de identificación y contacto de clientes, proveedores y empleados, como nombres, nombres de usuario, teléfonos y otros datos que se ingresen voluntariamente; (b) datos del negocio, como nombre comercial, dirección, teléfono, productos, precios, existencias, lotes y caducidades; (c) registros de ventas, compras, cotizaciones, pagos, devoluciones, movimientos de caja y reportes; (d) credenciales de acceso local, incluidos usuarios, valores de comprobación de PIN y roles o permisos; y (e) información técnica necesaria para vincular dispositivos autorizados dentro de una red local o seleccionar impresoras Bluetooth emparejadas.

No es necesario proporcionar datos personales de clientes para utilizar todas las funciones de venta. El negocio debe limitar los datos incorporados a los necesarios para sus operaciones.

3. Finalidades del tratamiento

Los datos se utilizan para registrar operaciones comerciales, consultar existencias y antecedentes de venta, elaborar tickets y cotizaciones, controlar accesos de empleados, producir reportes, crear respaldos, imprimir comprobantes y, cuando se activa, sincronizar datos entre equipos del mismo establecimiento.

4. Almacenamiento local y acceso del desarrollador

La edición revisada utiliza almacenamiento local privado de la aplicación en el dispositivo Android, incluido IndexedDB y ajustes internos para funciones concretas. No requiere una cuenta en un servidor NEXORA ni una conexión permanente a Internet para registrar ventas.

En el código revisado no se identificó una función que envíe automáticamente la base comercial a servidores del desarrollador para publicidad o análisis de uso. El desarrollador no tiene acceso remoto automático al inventario, los clientes ni las ventas guardadas en el teléfono.

5. Sincronización y transferencias opcionales

Cuando se habilita NEXORA Sync, un dispositivo principal puede intercambiar información comercial con otros teléfonos Android autorizados de la misma red Wi-Fi. El código revisado cifra el contenido de estas comunicaciones mediante AES-256-GCM. Esta función puede transmitir a los equipos autorizados los datos del negocio, incluidos clientes, empleados y transacciones que formen parte de la información sincronizada.

La función opcional para conectar NEXORA POS PRO con NEXORA Desktop emplea HTTP dentro de una red local privada. Esa comunicación no cuenta con cifrado HTTPS de transporte en la versión examinada. Se recomienda utilizar únicamente una red privada controlada, evitar redes Wi-Fi públicas y proteger el acceso al equipo Desktop.

También es posible exportar y restaurar archivos de respaldo JSON, así como generar y compartir reportes o comprobantes. Los archivos que el usuario guarde, copie o transmita quedan bajo su control y el de las aplicaciones o destinatarios que elija.

6. Cámara, Bluetooth y archivos

El permiso de cámara permite leer códigos de barras. La función de escaneo no necesita conservar imágenes de la cámara como parte del inventario.

El permiso de Bluetooth permite buscar o utilizar dispositivos previamente vinculados e imprimir tickets en impresoras compatibles.

La aplicación puede usar los mecanismos de Android para seleccionar archivos de importación, exportar respaldos y compartir imágenes de tickets, siempre a partir de acciones del usuario. La versión revisada no solicita permiso de ubicación geográfica.

7. Destinatarios y servicios de terceros

No se identificó en la versión revisada una función destinada a vender datos personales ni a transferir automáticamente la base comercial a redes publicitarias.

Si el usuario decide compartir tickets, archivos, respaldos o reportes mediante WhatsApp, correo electrónico u otra aplicación, los datos enviados serán tratados por el servicio seleccionado conforme a sus propias condiciones y políticas de privacidad. La sincronización local comparte información con los dispositivos que el administrador del negocio haya autorizado.

8. Seguridad

NEXORA POS PRO dispone de controles de acceso por usuario y PIN, permisos para distintos perfiles y mecanismos de vinculación de dispositivos. Las credenciales de acceso locales se someten a comprobación mediante valores derivados del PIN, según las funciones examinadas.

El PIN limita el acceso a la interfaz, pero por sí solo no cifra toda la base de datos almacenada. La seguridad también depende del bloqueo del teléfono, las actualizaciones del sistema, la protección de la red y la custodia de respaldos y dispositivos vinculados. Ningún sistema puede garantizar una protección absoluta.

9. Conservación, respaldos y eliminación

Los registros comerciales permanecen en los dispositivos que los almacenan mientras el negocio los conserve, los elimine mediante las opciones disponibles o borre los datos de la aplicación. La desinstalación o eliminación de datos de la aplicación normalmente suprime la copia local del teléfono, pero no borra los archivos de respaldo exportados ni las copias que existan en otros dispositivos autorizados. El administrador del establecimiento debe gestionar esas copias por separado y respetar los plazos legales de conservación aplicables a sus operaciones.

El administrador puede gestionar o eliminar perfiles locales de empleados desde las opciones disponibles en el POS. La baja de un perfil no implica necesariamente la supresión de todos los movimientos históricos asociados, que pueden ser necesarios para registros comerciales o exigencias legales.

Las solicitudes de acceso, rectificación o eliminación de información de clientes o empleados registrada por un establecimiento deben dirigirse en primer término al responsable de dicho establecimiento. Para consultas relacionadas con el funcionamiento de la aplicación o con los datos que, en su caso, controle el desarrollador, se dispone del contacto señalado en esta política.

10. Menores de edad

NEXORA POS PRO está diseñada para la operación de establecimientos comerciales y no está dirigida específicamente a menores de edad.

11. Cambios en esta política

La política podrá actualizarse cuando cambien las funciones de NEXORA POS PRO, sus mecanismos de sincronización, las prácticas de tratamiento de datos o las disposiciones aplicables. La fecha de actualización se mostrará en esta página.

Si una nueva versión incorpora servicios externos o usos de datos adicionales, se actualizará esta información y, cuando corresponda, la declaración de Seguridad de los datos de Google Play.
